C# core and framework

PolyCore.Core

Shared domain model, scene representation, metadata, capability contracts, diagnostics and orchestration.

PolyCore.Formats

Modular reader/writer adapters. JT parser integration can be native C# or DLL-backed behind a stable adapter.

PolyCore.Desktop

WinUI 3 Windows client, MVVM-oriented view models, import/export workflows, viewport host and job queue.

JT integration decision: first assess source access, licensing, API stability, target architecture, runtime dependencies, threading, memory ownership and exception boundaries. Prefer a managed adapter if source is available; otherwise isolate DLL calls behind a thin interop layer and test packaging.
