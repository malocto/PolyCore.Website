Compatibility planning

Format support, without ambiguity.

Format coverage is a roadmap, not a verified release-support promise. The implemented technical foundation is the C# JT reader in this repository. Each capability must be validated by format/version and data category. Explore a proposed support matrix by format family, operation and product tier. This matrix is a planning artifact and does not represent validated implementation support.

Convert & edit

FBX and USD-family workflows, scene operations, profiles and batch jobs.

Phase 03 · Enterprise

Engineering data

Evaluate STEP, IGES and IFC with licensing, dependencies and fidelity benchmarks.
