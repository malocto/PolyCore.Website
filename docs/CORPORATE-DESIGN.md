# PolyCore Corporate Design

## Brand
Technical, precise, future-facing and credible for engineering workflows. Cyberpunk accents should be restrained and functional, not overwhelming.

## Palette
- Midnight / background: `#0A0D12`
- Graphite surface: `#151B24`
- Elevated surface: `#202A36`
- Signal Yellow: `#FFD84D` — primary actions and key emphasis
- Technical Cyan: `#35D9F4` — data/technical indicators
- Violet: `#9B7BFF` — premium/module accents
- Mint: `#63E6B1` — success states
- Magenta: `#FF5CA8` — rare decorative accent
- Text: `#F3F6FA`; muted text: `#9AA8B7`

## Imagery
Prefer transparent-background PNGs for isolated product renders and UI composites so they integrate into page gradients. Use actual alpha transparency, not a checkerboard baked into pixels. Concept imagery must be labeled as illustrative; do not present generated UI as a screenshot of implemented software.

## UI principles
Strong hierarchy, generous spacing, thin borders, restrained glow, consistent radius, accessible contrast and responsive layouts. Yellow is reserved for primary action/highlight; cyan for technical data; violet for premium.
