# Website Professionalization Recommendations

## Positioning
Lead with the C# core/framework and WinUI 3 Windows desktop client. Present the existing JT parser as the initial technical foundation, not as validated full JT support until tests and capabilities are documented.

## Recommended trust content
- Supported Windows and .NET versions
- JT parser coverage and known limitations
- Format capability matrix with tested/read/write/edit distinctions
- Performance benchmarks with reproducible methodology
- Security, licensing and deployment notes
- Release notes and compatibility policy
- API documentation and sample projects

## Visual system
Use transparent-background product renders for hero compositions, real application screenshots once available, and dark UI concept panels for feature previews. Generated visuals must be labeled concept art. Preserve alpha channels and optimize PNG/WebP asset sizes.

## Information architecture
Home, Features, Formats, Developers, Pricing, Documentation, Support, Company.
